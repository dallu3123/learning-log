FPO 핵심 설명

왜 FPO는 likelihood 대신 CFM loss를 사용하는가?

기존 PPO는 action likelihood가 필요하지만, Flow policy에서는 그것을 직접 계산하기 어렵다. 그래서 FPO는 log-likelihood의 하한인 ELBO를 사용하고, 다시 ELBO를 CFM loss로 바꿔 PPO ratio처럼 사용한다.

우리가 원래 하고 싶은 것

일반적인 Policy Gradient나 PPO에서는, 어떤 상태 s에서 선택한 action a의 확률을 높이거나 낮추면서 policy를 학습한다.

\[\log \pi_\theta(a \mid s)\]

좋은 action이면 이 값을 키우고, 나쁜 action이면 이 값을 줄이고 싶다. Gaussian policy에서는 policy가 평균과 분산을 출력하므로, 아래 Gaussian pdf를 통해 action likelihood를 직접 구할 수 있다.

\[\pi_\theta(a \mid s) = \mathcal{N}\left(a;\mu_\theta(s),\sigma_\theta(s)^2\right)\]

PPO에서는 이 값을 이용해 현재 policy와 이전 policy의 likelihood ratio를 사용한다.

\[r(\theta) = \frac{\pi_\theta(a \mid s)}{\pi_{\mathrm{old}}(a \mid s)}\]
즉, PPO의 출발점은 “action likelihood를 계산할 수 있다”는 가정이다.

문제: Flow policy는 likelihood 계산이 어렵다

Gaussian policy는 평균과 분산만 알면 action의 확률밀도를 바로 계산할 수 있다. 하지만 Flow policy는 noise를 여러 단계의 flow를 통해 action으로 변환한다.

\[\varepsilon \sim \mathcal{N}(0, I) \rightarrow \text{flow integration} \rightarrow a\]

따라서 어떤 action a가 나왔을 때, 그 action이 현재 flow policy에서 얼마나 높은 확률로 나오는지 직접 계산하기 어렵다.

왜 마지막 action만 보면 안 되는가?

우리가 알고 싶은 값은 state \(s\)에서 최종 action \(a\)가 나올 확률밀도 \(\pi_\theta(a \mid s)\)이다. 그런데 Flow policy에서는 \(a\)가 바로 샘플링되는 것이 아니라, 쉬운 noise 분포에서 시작한 점이 flow를 따라 이동한 결과로 만들어진다.

\[z_0 \sim \mathcal{N}(0, I), \qquad z_0 \rightarrow z_1 \rightarrow \cdots \rightarrow z_T = a\]

따라서 \(a\)의 likelihood를 계산하려면 “어떤 \(z_0\)가 \(a\)가 되었는가?”뿐만 아니라, 그 변환 과정에서 확률밀도가 얼마나 압축되거나 팽창했는지도 알아야 한다.

예를 들어 1차원에서 \(a = 2z\)처럼 공간을 두 배로 늘리는 변환을 생각하면, 같은 확률 질량이 더 넓은 구간에 퍼지므로 밀도는 절반으로 줄어든다.

\[p(a) = p(z)\left|\frac{dz}{da}\right|\]

고차원에서는 이 압축과 팽창 정도가 Jacobian determinant로 표현된다.

\[\log p(a) = \log p(z_0) - \log \left|\det \frac{\partial a}{\partial z_0}\right|\]

Continuous flow에서는 변환이 한 번에 끝나지 않고 ODE처럼 연속적으로 진행된다.

\[\frac{dz_t}{dt} = v_\theta(z_t, t, s)\]

이때 확률밀도의 변화는 velocity field의 divergence로 결정된다. 주변 점들이 퍼지면 밀도가 낮아지고, 모이면 밀도가 높아진다.

\[\frac{d \log p(z_t)}{dt} = -\nabla \cdot v_\theta(z_t, t, s)\]
\[\log p(a) = \log p(z_0) - \int_0^T \nabla \cdot v_\theta(z_t, t, s)\,dt\]
  • \(a\)에 대응되는 시작점 \(z_0\)를 찾아야 한다.
  • \(z_t\)가 지나가는 경로를 ODE로 따라가야 한다.
  • 각 시간에서 divergence 또는 Jacobian 관련 값을 계산해야 한다.
  • 그 값을 전체 시간 구간에 대해 적분해야 한다.
즉, likelihood 계산은 처음 noise의 확률과 flow가 공간을 얼마나 압축/팽창시켰는지를 모두 추적하는 문제다. 특히 action dimension이 커질수록 Jacobian이나 divergence 관련 계산이 더 비싸진다.
그래서 기존 PPO ratio를 그대로 쓰기 어렵다.

핵심 아이디어: log-likelihood 대신 ELBO를 사용한다

Flow / diffusion 모델에서는 정확한 log-likelihood 대신, 그 하한인 ELBO를 최적화하는 방식이 많이 사용된다.

왜 ELBO가 나오는가?

2번에서 문제가 된 것은 최종 action \(a\)의 likelihood를 계산하려면, 그 action이 만들어질 수 있는 hidden noise나 latent path를 모두 고려해야 한다는 점이었다.

\[\pi_\theta(a \mid s)=\int \pi_\theta(a,z \mid s)\,dz\]

여기서 \(z\)는 action을 만들기 위해 거쳐간 hidden variable 또는 path를 의미한다. 문제는 가능한 \(z\)를 모두 적분한 뒤 log를 취해야 하므로, 아래 값이 직접 계산하기 어렵다는 것이다.

\[\log \pi_\theta(a \mid s)=\log \int \pi_\theta(a,z \mid s)\,dz\]

그래서 variational inference에서는 계산 가능한 보조 분포 \(q(z \mid a,s)\)를 도입한다. 이 \(q\)는 “이 action \(a\)가 어떤 latent path에서 왔을까?”를 설명하는 분포로 볼 수 있다.

\[\mathrm{ELBO}_\theta(a)=\mathbb{E}_{q(z\mid a,s)}\left[\log \frac{\pi_\theta(a,z\mid s)}{q(z\mid a,s)}\right]\]

Jensen inequality 때문에 이 값은 진짜 log-likelihood보다 작거나 같은 lower bound가 된다.

\[\mathrm{ELBO}_\theta(a) \le \log \pi_\theta(a \mid s)\]

여기서 중요한 관계는 다음과 같다.

\[\log \pi_\theta(a \mid s) = \mathrm{ELBO}_\theta(a) + \mathrm{KL}\]
\[\mathrm{ELBO}_\theta(a)=\log \pi_\theta(a\mid s)-\mathrm{KL}\]

KL divergence는 항상 0 이상이므로, ELBO는 log-likelihood보다 작거나 같은 값이 된다.

즉, ELBO는 log π와 같은 값이 아니라, log π를 아래에서 근사하는 계산 가능한 proxy이다.

왜 ELBO를 올리면 좋은가?

ELBO는 log-likelihood의 lower bound이므로, ELBO를 크게 만들면 해당 action을 policy가 더 잘 설명하도록 만드는 효과가 있다.

ELBO와 CFM loss의 연결

Flow matching에서는 action에 noise를 섞은 뒤, 모델이 올바른 velocity 또는 denoising 방향을 예측하도록 학습한다.

\[\mathcal{L}_{\mathrm{CFM}} = \mathbb{E}\left[\left\lVert v_\theta(a_\tau, \tau, s) - \mathrm{target}\right\rVert^2\right]\]

diffusion / flow matching 이론에서 이 denoising 계열 loss는 ELBO와 연결된다. 직관적으로는, noise를 잘 제거할수록 해당 action distribution을 잘 모델링한다는 뜻이다.

\[\mathcal{L}_{\mathrm{CFM}} \approx -\mathrm{ELBO} + \mathrm{constant}\]
따라서 CFM loss가 작아지면 ELBO가 커지고, 결과적으로 action likelihood를 높이는 효과가 난다.

최종 결론: FPO ratio

PPO는 원래 likelihood ratio를 사용한다. 하지만 FPO는 likelihood를 직접 계산하지 않고, ELBO ratio를 사용한다.

\[r_{\mathrm{FPO}}(\theta) = \exp\left(\mathrm{ELBO}_\theta - \mathrm{ELBO}_{\mathrm{old}}\right)\]

그리고 ELBO는 CFM loss의 음수와 연결되므로 다음과 같이 바뀐다.

\[r_{\mathrm{FPO}}(\theta) = \exp\left(\mathcal{L}_{\mathrm{old}} - \mathcal{L}_\theta\right)\]

결국 FPO의 핵심은 이것이다.

좋은 action → CFM loss 감소 → ELBO 증가 → likelihood 증가
