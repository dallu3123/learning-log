FPO 핵심 설명

왜 FPO는 likelihood 대신 CFM loss를 사용하는가?

발표 핵심은 다음 흐름이다. 기존 PPO는 action likelihood가 필요하지만, Flow policy에서는 그것을 직접 계산하기 어렵다. 그래서 FPO는 log-likelihood의 하한인 ELBO를 사용하고, 다시 ELBO를 CFM loss로 바꿔 PPO ratio처럼 사용한다.

1

우리가 원래 하고 싶은 것

일반적인 Policy Gradient나 PPO에서는, 어떤 상태 s에서 선택한 action a의 확률을 높이거나 낮추면서 policy를 학습한다.

\[\log \pi_\theta(a \mid s)\]

좋은 action이면 이 값을 키우고, 나쁜 action이면 이 값을 줄이고 싶다. PPO에서는 현재 policy와 이전 policy의 likelihood ratio를 사용한다.

\[r(\theta) = \frac{\pi_\theta(a \mid s)}{\pi_{\mathrm{old}}(a \mid s)}\]
즉, PPO의 출발점은 “action likelihood를 계산할 수 있다”는 가정이다.
2

문제: Flow policy는 likelihood 계산이 어렵다

Gaussian policy는 평균과 분산만 알면 action의 확률밀도를 바로 계산할 수 있다. 하지만 Flow policy는 noise를 여러 단계의 flow를 통해 action으로 변환한다.

\[\varepsilon \sim \mathcal{N}(0, I) \rightarrow \text{flow integration} \rightarrow a\]

따라서 어떤 action a가 나왔을 때, 그 action이 현재 flow policy에서 얼마나 높은 확률로 나오는지 직접 계산하기 어렵다.

그래서 기존 PPO ratio를 그대로 쓰기 어렵다.
3

핵심 아이디어: log-likelihood 대신 ELBO를 사용한다

Flow / diffusion 모델에서는 정확한 log-likelihood 대신, 그 하한인 ELBO를 최적화하는 방식이 많이 사용된다.

\[\mathrm{ELBO}_\theta(a) \le \log \pi_\theta(a \mid s)\]

여기서 중요한 관계는 다음과 같다.

\[\log \pi_\theta(a \mid s) = \mathrm{ELBO}_\theta(a) + \mathrm{KL}\]

KL divergence는 항상 0 이상이므로, ELBO는 log-likelihood보다 작거나 같은 값이 된다.

즉, ELBO는 log π와 같은 값이 아니라, log π를 아래에서 근사하는 계산 가능한 proxy이다.
4

왜 ELBO를 올리면 좋은가?

ELBO는 log-likelihood의 lower bound이므로, ELBO를 크게 만들면 해당 action을 policy가 더 잘 설명하도록 만드는 효과가 있다.

ELBO와 CFM loss의 연결

Flow matching에서는 action에 noise를 섞은 뒤, 모델이 올바른 velocity 또는 denoising 방향을 예측하도록 학습한다.

\[\mathcal{L}_{\mathrm{CFM}} = \mathbb{E}\left[\left\lVert v_\theta(a_\tau, \tau, s) - \mathrm{target}\right\rVert^2\right]\]

diffusion / flow matching 이론에서 이 denoising 계열 loss는 ELBO와 연결된다. 직관적으로는, noise를 잘 제거할수록 해당 action distribution을 잘 모델링한다는 뜻이다.

\[\mathcal{L}_{\mathrm{CFM}} \approx -\mathrm{ELBO} + \mathrm{constant}\]
따라서 CFM loss가 작아지면 ELBO가 커지고, 결과적으로 action likelihood를 높이는 효과가 난다.
6

최종 결론: FPO ratio

PPO는 원래 likelihood ratio를 사용한다. 하지만 FPO는 likelihood를 직접 계산하지 않고, ELBO ratio를 사용한다.

\[r_{\mathrm{FPO}}(\theta) = \exp\left(\mathrm{ELBO}_\theta - \mathrm{ELBO}_{\mathrm{old}}\right)\]

그리고 ELBO는 CFM loss의 음수와 연결되므로 다음과 같이 바뀐다.

\[r_{\mathrm{FPO}}(\theta) = \exp\left(\mathcal{L}_{\mathrm{old}} - \mathcal{L}_\theta\right)\]

결국 FPO의 핵심은 이것이다.

좋은 action → CFM loss 감소 → ELBO 증가 → likelihood 증가
