Flow Matching
for Generative Modeling

The starting point of modern flow matching: learning a continuous vector field that transports noise into data without simulating an ODE during training.

Big picture

이 논문이 만든 출발점

이 논문은 Continuous Normalizing Flow(CNF)를 대규모로 학습하는 간단한 방법을 제안한다. 핵심은 noise에서 data로 가는 전체 확률 분포 경로를 정하고, 그 경로를 움직이는 vector field를 신경망이 회귀하도록 만드는 것이다.

1

Simulation-free training

학습 단계에서는 ODE를 풀지 않는다. 각 시간의 정답 velocity를 직접 맞춘다.

2

Conditional Flow Matching

계산하기 어려운 전체 경로 대신, 데이터 샘플 하나에 조건부인 쉬운 경로를 사용한다.

3

Paths beyond diffusion

diffusion path뿐 아니라 Optimal Transport(OT) path처럼 직접 설계한 경로도 쓸 수 있다.

Step 1 · CNF

생성은 vector field를 따라가는 ODE다

시작 분포 (p_0)에서 noise (x_0)를 뽑는다. 시간과 현재 위치를 입력받는 신경망 (v_t(x;\theta))가 어느 방향으로 움직일지 정하고, ODE를 (t=0)부터 (1)까지 풀면 샘플은 data 분포 (p_1)로 운반된다.

Continuous Normalizing Flow

학습할 대상은 이미지 자체가 아니라, 위치별 이동 방향인 time-dependent vector field다.

\[\frac{d\phi_t(x)}{dt}=v_t(\phi_t(x);\theta),\qquad \phi_0(x)=x\]

Step 2 · Flow Matching

원하는 확률 경로의 velocity를 맞춘다

어떤 확률 경로 (p_t(x))와 이를 생성하는 target vector field (u_t(x))가 있다면, Flow Matching은 모델 (v_t)가 (u_t)를 회귀하도록 학습한다. loss가 충분히 작아지면 배운 CNF도 같은 분포 경로를 만든다.

FM objective

문제는 실제 data 분포에서 만든 marginal (u_t)를 직접 계산하기 어렵다는 점이다.

\[\mathcal{L}_{\mathrm{FM}}(\theta)=\mathbb{E}_{t,\,x\sim p_t}\left\|v_t(x;\theta)-u_t(x)\right\|^2\]

Step 3 · Conditional Flow Matching

어려운 전체 경로를, 쉬운 샘플별 경로로 바꾼다

data sample (x_1\sim q) 하나를 고정하고, standard Gaussian noise에서 (x_1) 근처로 가는 조건부 경로 (p_t(x\mid x_1))를 만든다. 이 경로의 velocity (u_t(x\mid x_1))는 닫힌 형태로 계산할 수 있다.

CFM objective

논문의 핵심 정리: CFM과 원래 FM은 \(\theta\)에 대한 gradient가 같다. 따라서 이 실용적인 loss만 최적화하면 된다.

\[\mathcal{L}_{\mathrm{CFM}}(\theta)=\mathbb{E}_{t,\,x_1,\,x\sim p_t(\cdot\mid x_1)}\left\|v_t(x;\theta)-u_t(x\mid x_1)\right\|^2\]
한 문장으로: 데이터 전체를 설명하는 velocity를 직접 구하지 않고, 각 데이터 샘플로 향하는 간단한 velocity를 맞춰 같은 학습 방향을 얻는다.

Step 4 · Path design

Diffusion path와 OT path

CFM은 조건부 확률 경로만 정의할 수 있으면 동작한다. 논문은 Gaussian path의 일반형을 제시하고, 기존 diffusion path와 직선적인 OT displacement interpolation을 비교한다.

Diffusion path

끝에서야 noise가 빠지는 곡선 경로

기존 diffusion process에서 유도할 수 있다. 널리 쓰이지만, 경로가 휘고 sampling 중 backtracking이 나타날 수 있다.

OT path

직선, 일정한 속도의 조건부 경로

mean과 standard deviation을 선형으로 바꾼다. regression target이 단순해져 더 빠른 학습과 sampling을 기대할 수 있다.

OT conditional path: \(\psi_t(x_0)=[1-(1-\sigma_{\min})t]x_0+t x_1\). 각 particle은 noise에서 target sample 쪽으로 곧게 이동한다.

Results

논문의 실험 메시지

Better qualityImageNet과 CIFAR-10에서 FM with OT가 비교 방법보다 좋은 FID와 likelihood를 보였다.
Faster samplingOT path는 적은 NFE로도 낮은 ODE error와 좋은 sample quality를 유지했다.
Beyond images64×64에서 256×256으로의 conditional super-resolution에도 적용했다.

Takeaway

Flow Matching은 “diffusion process”가 아니라 “probability path”를 직접 설계하게 만들었다.

이 관점은 이후 flow-matching policy, robot action generation, rectified flow 등으로 이어지는 기반이 된다. 다음에는 OT path의 식과 diffusion/score matching과의 관계를 더 자세히 확장할 수 있다.
